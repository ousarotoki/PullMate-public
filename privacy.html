Privacy Policy

PullMate is a Chrome extension that enhances GitHub pull request reviews. It does not collect, store, or transmit any personal data to external servers beyond what is described below.

Data Storage

All user data (review progress, notes, settings, license information) is stored locally in your browser using chrome.storage.local and chrome.storage.session. No data is sent to any server by the extension itself.

Error Reporting

If enabled, anonymous error reports are sent to Sentry (@sentry/browser). These reports contain technical information about the error (stack trace, browser version) but no personal data, code content, or identifying information.

License Validation

When you activate a Pro license key, the key is sent to Lemon Squeezy for validation. No other personal information is transmitted.

Third-Party Services

  • Sentry — error monitoring (opt-in via extension settings)
  • Lemon Squeezy — license key validation
